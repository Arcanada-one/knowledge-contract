# Sources and attribution register

This register covers the current publication and its supporting evidence. The [primary bibliography](reference/bibliography/BIBLIOGRAPHY.md) identifies each external work and the claim for which it is used. The [source map](appendices/source-map/APPENDIX.md) identifies the immutable earlier corpus. A table entry is attribution and provenance, not a claim that a source endorses the project or that all reported experiments can be independently rerun.

## Rule

Every file under `papers/`, `spec/`, `engineering/`, `reference/`, `appendices/` and `reviews/` must be covered by a named source row with its path in the final cell, or a valid registered `sources:` declaration in Markdown front matter. Use `sources: none` only for an original document without external sources. An empty list or unspecified catch-all source is insufficient.

Project text retains CC BY 4.0 and code Apache-2.0. Third-party source works retain their own terms. This edition links primary works and contains original explanations; it does not redistribute the books, page images or OCR material used in some historical experiments. Exact retained JSON, reconstructed prose views, extracted metadata and new public demonstrations are distinguished in each study's `evidence/origin.json`.
