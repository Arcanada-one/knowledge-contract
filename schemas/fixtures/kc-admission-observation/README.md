# Synthetic KCAdmissionObservation/v1 (CANDIDATE) records

Every file here is invented for this repository and is a fixture, not a native observation: the source system is `synthetic-fixture` and every record id starts `synthetic:`. `valid/` holds six records (observed `contract` with verified exact-byte provenance, a `K` contract that keeps its obligation, a contract with an evidenced work item, observed `underdetermined`, observed `refusal`, and `unavailable`); passing them is a statement about the checker's rules only, not about Argana, Muneral or any admission. `NAME.source.json` holds the exact synthetic native record bytes whose SHA-256 is `native_source.sha256`; `NAME.work-item.json` holds the exact synthetic work item record bytes. Each file under `invalid/` is a mutant with one defect and one expected refusal code (see `EXPECTED` in `tools/kc_admission_observation_fixture.py`). Regenerate with
`python3 tools/kc_admission_observation_fixture.py write`; the unit tests fail if the committed files drift.
