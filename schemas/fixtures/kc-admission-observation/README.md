# Synthetic KCAdmissionObservation/v1 (CANDIDATE) records

Every file here is invented for this repository and is a fixture, not a native observation: the source system is `synthetic-fixture` and every record id starts `synthetic:`. Synthetic labels and the work item binding are valid ONLY in explicit fixture mode (`--fixture`); without it they are refused, and a fixture pass has the level `fixture-evidence`, never a native observation. `valid/` holds eight records (observed `contract` with verified exact-byte provenance, a `K` contract that keeps its obligation, a contract with an evidenced synthetic work item, observed `underdetermined`, observed `refusal`, an observed `refusal` whose source records no verdict, `unavailable` with a typed reason, and `unavailable` / `native_binding_unverified` whose `subject` is the requested target only); passing them is a statement about the checker's rules only, not about Argana, Muneral or any admission. `NAME.source.json` holds the exact synthetic native record bytes whose SHA-256 is `native_source.sha256`: an `ArganaContractRecord/v1`-shaped record for the `contract` branch (the only branch the Argana record can support) or a `SyntheticNativeDecision/v1` record that carries every fact an `underdetermined` or `refusal` observation asserts; `NAME.work-item.json` holds the exact synthetic `SyntheticWorkItemRecord/v1` bytes. The real digest-named Argana record is mutable metadata and cannot be an immutable intake event, so until native capture exists the honest live result is `unavailable`. Each file under `invalid/` is a mutant with one defect and one expected refusal code (see `EXPECT` in `tools/kc_admission_observation_fixture.py`); a sidecar defect is re-hashed so the case reaches the intended comparison, except the two `*_do_not_match_the_digest` mutants. Regenerate with
`python3 tools/kc_admission_observation_fixture.py write`; the unit tests fail if the committed files drift.
