# Engineering

Engineering documents define requirements and examine what implementations actually do. Domain-specific examples and finite experiment results belong here.

- [Specifications](specifications/README.md): core model, operations, representations, context, artifacts, states, reuse and evolution.
- [Studies and evidence](studies/README.md): seven study reports with raw records, adverse cases and available public replays.
- [Claim–evidence index](studies/evidence-index.json): 26 claims linked to supporting records, counterexamples and limitations.
- [Artifact Registry](specifications/artifact-registry/SPECIFICATION.md): readable folders and canonical Markdown files, including roles, skills, competencies, blueprints and constraints.
- [Publication Interfaces](../appendices/api-integration/APPENDIX.md): the published read surface, requirements for task-specific contracts and release consistency.

The [scientific papers](../papers/README.md) state the arguments these requirements and studies examine. [Publication home](../README.md).
