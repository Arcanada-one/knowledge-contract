# Meaning Management specifications

Ten specifications cited by the [papers](../papers/README.md), released as scientific drafts. Each has an English entry page that summarises the specification's own statements and a Russian full text. The status of each is stated in its entry page; none is an approved schema, a finished interface or a runtime claim.

## Language and status

- The full texts are Russian originals. The English entry pages are summaries, not translations. A full English translation has not been started.
- The late research synthesis gate is open and independent semantic review has not been performed.
- Relative to the source text the release changed only front-matter keys, and link targets: links to released documents point at their repository path; links to supporting records that are not released are shown with a marker (see [papers/README.md](../papers/README.md)).
