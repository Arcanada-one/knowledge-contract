# 语义对象、上下文与适用条件 {#semantic-objects-context-and-conditions-of-applicability}

**作者：** Pavel Valentov · **出版版本：** 1.1

## 摘要 {#abstract}

忠实提取本身并不能确立来源内容为真，也不能确立其适合某项任务。本文探讨知识系统在来源材料与材料的使用之间必须保留哪些区分。我们定义一种版本化语义对象，其中包含具有归属标注的内容、明确的上下文和可供检查的依据，并相对于已声明的要求与评估定义经确认的适用性。五项基本的条件性结果刻画了该模型：仅凭忠实性无法在观察上相同的世界之间辨别真值；有限依赖图具有最小必需闭包；强化强制要求会缩小经确认的适用范围；增加可能的解读会缩小共同后果的集合；完整的后向切片会保留选定的确定性输出。反例界定了这些结果的适用边界：计算出的闭包可能遗漏未记录的例外，保留的引文可能为假，表示也可能丢失否定或义务的作用域。本文的贡献是对提取与使用之间的义务给出一体化描述，而不是提出新的普遍意义理论。方法是演绎性的；解释过程是否提供完整而正确的表示，仍是一个独立的经验问题。已发表的工程研究提供了范围有限的转录与依赖证据，而不是对完整语义提取的证明。

**关键词：** 语义对象；溯源；上下文；适用性；解释；依赖闭包。

## 1. 研究问题与贡献 {#1-research-question-and-contribution}

准确复现的引文可能包含错误的断言。真实的陈述可能与任务无关。相同的句子可能涉及不同的对象、日期或义务。文本和单一置信分数无法区分这些情况，除非系统把互不相容的含义赋给同一个字段。

我们的问题是：**当来源材料成为面向特定任务提供的知识时，哪些内容必须保持明确？** 我们区分五个问题：检查了哪一种表示？如何解释它？哪些依据支持该解释？哪些要求约束拟议的使用？哪些材料实际到达了接收方？对其中一个问题作出有利回答，并不能解决其他问题。

本文的贡献在于组织这些义务及其失效条件。语义对象记录将归属标注和上下文与可检查的依据联系起来。适用性定义明确了强制条件和有正当依据的豁免。条件性结果指出哪些结论来自这些定义，哪些仍然需要独立证据。它们是基本结果，并非宣称提出了新的普遍意义理论或新的提取算法。

本文采用演绎方法。第2节和第3节定义对象及适用性确认规则。第4节提出五个命题，给出各自的假设、证明和限制。第5节和第6节讨论粒度、交付与经验评估；第7节指出已发表工程研究所处理的较窄问题。这些证明并不能确立某个提取过程满足其前提。

本模型补充了已有工作。W3C PROV-DM 通过实体、活动和代理描述溯源关系 [1]。SKOS 为知识组织提供概念、标签和关系 [2]。单凭溯源链接或概念标签，不能确立命题为真，也不能确立其适合某项任务。本文处理的问题是：在一种解释能够支持特定使用之前，还必须满足哪些额外条件。

## 2. 对象、解释与依据 {#2-objects-interpretations-and-grounds}

**来源表示**是材料的特定版本，例如文本、图像、表格、音频或其组合。定位符标识该表示内部的一个区域。定位符可以使检查具有可重复性，但并不确认对该区域的解释正确。

**语义对象**是一条记录：

\[
o=(i,v,m,A,C,G),
\]

其中，\(i\) 是身份，\(v\) 是修订版，\(m\) 是所表示的内容，\(A\) 是归属标注，\(C\) 是上下文，\(G\) 是依据与依赖关系的集合。

所表示的内容可以是命题、问题、指令、约束、示例，或者其他已声明的内容角色。该角色描述记录所表示的内容，并不是认识论判断。记录一条指令并不能确立其正当性；记录一个示例也不能确立一条普遍规则。

**解释**是在已声明的解读假设下，将来源区域映射为语义对象记录的过程。解释可以保持不确定，也可以容许多种解读。当一幅图容许两种解读时，记录可以保留两者，并指出消除歧义所需的观察。默默选择其中一种会改变知识主张，而不只是简化呈现方式。

**依据关联**说明解释中的某一部分为何得到支持。来源可以支持“作者断言了 \(P\)”这一主张，而独立测量可以支持 \(P\) 本身。这是不同的依据。因此，我们区分：

\[
\operatorname{Says}(a,P) \quad\text{and}\quad P.
\]

在没有关于来源及相关领域的额外前提时，前者并不蕴含后者。因此，忠实的归属标注与真实性需要不同的论证。

共同出现也不是蕴含关系。两个陈述出现在同一段落中，并不会仅因彼此相邻就获得因果关系或逻辑关系。

当逻辑结构具有实质意义时，提取必须保留它。对于一个包含两个对象的论域，若其中一个满足 \(P\)，另一个不满足，则“并非每个对象都满足 \(P\)”为真，而“每个对象都不满足 \(P\)”为假。同样，没有行动义务不同于负有不行动的义务。即使保留了大部分词语，把这些区分合并的语义表示仍然改变了主张。

## 3. 上下文与适用性 {#3-context-and-applicability}

在本模型中，上下文承担六种不同的功能。

**表1. 上下文角色及其标识的信息。**

| 上下文角色 | 相关信息 |
| --- | --- |
| 来源 | 来源中的术语、指称对象和局部图例。 |
| 提取 | 已检查的表示和尚未解决的细节。 |
| 请求 | 意图、完整性要求和预算。 |
| 接收方 | 可用的形式与模态。 |
| 情境 | 目标对象、时间和参照框架。 |
| 预期行动 | 要解释、比较、计算或执行的内容。 |

这些是功能角色，不是同一数值或内容的六份必需副本。一个通过链接关联的值可以承担多种角色。不过，表示仍须区分附属于来源的条件与约束预期目标用途的条件。

设使用请求为 \(q\)，相关状态为 \(s\)，有限的已声明强制条件集合为 \(R(q)\)。每个条件具有一个评估：

\[
e_r(o,q,s)\in\{\mathsf{pass},\mathsf{fail},\mathsf{unknown},\mathsf{not\_applicable}\}.
\]

当条件通过评估，或者有正当依据的适用性规则确立该条件在精确的评估范围内不施加义务时，称该条件的义务**已履行**（discharged）。用 \(w_r(o,q,s)\) 表示该规则应用及其支持性见证的有效性。于是：

\[
\operatorname{Discharged}_r(o,q,s)
\iff e_r(o,q,s)=\mathsf{pass}
\ \lor\ \bigl(e_r(o,q,s)=\mathsf{not\_applicable}\land w_r(o,q,s)\bigr).
\]

该见证标识规则、规则的依据，以及它所适用的对象和范围。仅有 `not_applicable` 标签并不足够。经确认的适用性定义为：

\[
\operatorname{Applicable}(o,q,s)
\iff \forall r\in R(q),\ \operatorname{Discharged}_r(o,q,s).
\]

这个定义采用与[状态模型（英文原文）](https://github.com/Arcanada-one/knowledge-contract/blob/a0450428704fcd41b411203f2fc88c06c779610b/engineering/specifications/status-model/SPECIFICATION.md)相同的四个评估值。它不把未知视为通过，也不允许没有依据的豁免。它同样不把无法确认适用性等同于证明内容为假。一个关于相关日期而尚未得到回答的问题，可能阻止当前建议的提出，同时让底层陈述保持未决。

确认的可靠程度取决于已声明条件、评估和豁免规则的完整性与正确性。如果 \(R(q)=\varnothing\)，上述全称量化在空集上真空成立；这并不能确立该请求没有实质义务。因此，若要用这样的确认来支持具有实际后果的使用，就必须另行论证要求集合覆盖了该用途。

条件只能通过已声明的规则继承。章节级例外可以适用于其中的段落，但任意的文本邻近并不能确立继承关系。相互冲突的条件需要明确的冲突处理决定，或者范围受限的回答。系统不能挑选恰好产生方便结果的条件。

请求决定所需的深度。一个简短的识别问题，可能比执行具有实际后果的行动指令需要更少的依赖。增加深度可能产生新的义务，而不只是要求更长的回答。还必须针对实际接收方和已交付表示检查适用性。系统能够访问、但未包含在交付指令中的条件，未必能保护接收方。

## 4. 条件性结果 {#4-conditional-results}

### 命题1. 忠实性无法区分不可区分的世界 {#proposition-1-fidelity-cannot-discriminate-indistinguishable-worlds}

假设两个可能世界产生相同的可观察来源表示，而 \(P\) 在其中一个世界为真、在另一个世界为假。任何只使用该表示的确定性过程，在两个世界中都会产生相同的判定。因此，它不可能在两个世界中都正确判定 \(P\) 的真值。

**证明。** 过程接收相同的输入，因此其输出相同。正确的真值判断却不同。所以，如果过程返回确定的真值，至少有一个判断是不正确的。随机化过程在两个世界中的输出分布相同，也同样没有获得能够区分它们的证据。∎

这一结果并不意味着来源没有用处。它指出从忠实归属标注转向真实性主张所需的额外前提：可靠的领域模型、独立观察，或者另一项有正当依据且能够区分情形的依据。

### 命题2. 有限图上存在最小必需闭包 {#proposition-2-least-required-closure-exists-on-a-finite-graph}

设 \(V\) 为有限的、版本已固定的对象修订版集合，\(\mathit{Roots}\subseteq V\) 为选定的根，\(D_q\subseteq V\times V\) 为针对固定请求处于生效状态的强制依赖。定义：

\[
C_0=\mathit{Roots},\qquad
C_{n+1}=C_n\cup\{v:\exists u\in C_n,(u,v)\in D_q\}.
\]

该序列会到达不动点 \(C^*\)，它是包含 \(\mathit{Roots}\) 的最小 \(D_q\)-闭合集合。

**证明。** 该序列单调递增，且包含于有限集合 \(V\) 中，因此只能发生有限次严格增加。按构造，其不动点是闭合的。对于任何包含 \(\mathit{Roots}\) 的闭合集合 \(S\)，归纳可得每个 \(n\) 都满足 \(C_n\subseteq S\)。因此 \(C^*\subseteq S\)。∎

环不会使这一集合论结果失效。[经过测试的工程配置（英文原文）](https://github.com/Arcanada-one/knowledge-contract/blob/a0450428704fcd41b411203f2fc88c06c779610b/engineering/studies/dependency-closure-and-package-delivery/STUDY.md)拒绝环；因此，它的可执行证据覆盖的是无环配置，而此处的有环情形由证明支持。遗漏的边会使“计算出的闭包意味着语义完整”这一解释失效：即使闭包计算完全正确，它仍然可能遗漏未记录的例外。

“最小”是相对于已声明的顶点和边而言的。[投影研究中的反例（英文原文）](https://github.com/Arcanada-one/knowledge-contract/blob/a0450428704fcd41b411203f2fc88c06c779610b/engineering/studies/executable-projections-and-revision/STUDY.md#counterexample-to-claim-level-minimality)表明，即使实体闭包最小，共用的限定条件中仍可能携带不必要的主张。该命题既不确立主张层面的最小性，也不确立最小令牌预算。

### 命题3. 强化强制要求会缩小经确认的适用范围 {#proposition-3-mandatory-strengthening-narrows-certified-applicability}

设 \(R\subseteq R'\)，并保持共有条件的评估、豁免见证和义务履行语义不变。凡在 \(R'\) 下获得适用性确认的对象，也都在 \(R\) 下获得适用性确认。

**证明。** 履行 \(R'\) 中每个条件的义务，蕴含履行其子集 \(R\) 中每个条件的义务。∎

语义保持不变这一条件十分重要。如果新增要求同时改变了某项原有要求的含义，那么这种比较就不再是单纯的强化。

### 命题4. 增加解读会缩小共同后果的集合 {#proposition-4-additional-readings-narrow-common-consequences}

对于非空的可能解读集合 \(I\)，在固定的后果关系下，设 \(K(I)=\bigcap_{i\in I}\operatorname{Conseq}(i)\)。如果 \(I\subseteq I'\)，则 \(K(I')\subseteq K(I)\)。

**证明。** 属于以 \(I'\) 为索引的交集，要求属于以 \(I\) 中每个元素为索引的集合，也要求属于所有新增的集合。∎

这为歧义条件下的保守报告提供支持。但它并不能确立已记录的解读包含正确解读，也不能确立所用后果关系对该领域是可靠的。

### 命题5. 完整后向切片保留选定的确定性输出 {#proposition-5-a-complete-backward-slice-preserves-selected-deterministic-outputs}

设一个有限无环计算图具有固定的确定性节点函数和固定输入值。保留选定的输出节点以及它们所依赖的每一个节点。对保留的图求值，会得到与完整图求值相同的选定输出。

**证明。** 按拓扑顺序排列保留的图。保留的输入节点具有不变的值。此后每个保留节点的全部前驱也都被保留，并且根据归纳假设，该节点接收到的前驱值没有变化。因此，其固定函数返回相同的值。这也包括选定的输出。∎

该结果涉及完整的计算依赖。隐藏输入、变化的函数、遗漏的边，或者不能充分表示原任务的模型，都会破坏其前提。它是程序切片研究中行为保持义务 [3] 的一个受限无环实例，而不是新的切片算法。将这一义务用于知识，还需要有正当依据的解释和任务范围；该结果不能证明任意文本摘要都保留了意义。

## 5. 粒度、身份与交付 {#5-granularity-identity-and-delivery}

语义对象不存在独立于任务的理想大小。较大的单元可能隐藏例外；过小的单元可能使谓词脱离其作用域。当分解能够在不丢失强制联系的情况下支持独立修订与检查时，它才是有用的。分解是否充分取决于重建和使用义务，而不是偏好的字数。

身份、内容等价和使用上的可互换性回答的是不同问题。具有等价主张的记录可能具有不同的溯源关系。同一记录的修订版可能在关键条件上不同。对一个问题可互换的对象，对另一个问题可能可以区分。因此，去重应当保留用于支持或限定已验证内容等价类成员的溯源信息。

交付必须单独检查。保留图像标识符并不能确立接收方收到了可读图像。替代文本可能遗漏任务所需的视觉关系。交付的包必须包含相关材料，或以可用分辨率提供对它们的访问，并附带必要的图例或解释。仅仅命名一个多模态字段，并不能确立这些工程条件已经满足。

## 6. 证伪与证据范围 {#6-falsification-and-scope-of-evidence}

这些命题讨论的是在已陈述前提下的已声明表示。另一个独立的经验问题是：提取过程能否提供正确的表示和依赖。测试该过程需要独立准备的案例及裁定规则。评估应区分转录错误、归属标注错误、逻辑作用域错误、遗漏的上下文和缺乏依据的推断。单一的汇总准确率可能掩盖这些不同的失效机制。

测试案例应包含：措辞不变但指称对象改变、例外位于提取区域之外、含糊的视觉标记，以及对错误断言的正确引用。独立的参考标注应明确可接受的替代解读。如果两个输出都继承了同一项被遗漏的条件，那么它们彼此一致仍然不足以构成充分证据。

即使闭包计算正确，遗漏的依赖也可能使系统关于语义完整性的主张失效。这类案例质疑的是所表示依赖的完整性，而不是反驳针对实际已声明图的条件性闭包结果。当实现不满足其他命题的前提时，同样需要作出这种区分。针对条件命题的反例，必须满足其前提并与其结论相矛盾。

本文确立了所陈述的条件性性质，并把提取义务表述得足够明确，以便评估。它没有报告任何模型、标注过程或用户界面的测量优势。可执行示例可以在有限输入上测试符合性，但不能确立对不受限语言或图像的完整解释能力。下文指出已发表的观察及其尚未测试的边界。

## 8. 结论 {#8-conclusion}

来源忠实性、有依据的解释、经确认的适用性和成功交付是不同的义务。语义对象记录使归属标注、上下文和依据能够接受检查；适用性规则询问每一个已声明强制条件是否通过评估，或者在评估范围内是否具有正当豁免。定位符和置信标签都不能独自解决这些问题。

五个命题描述的是条件性保证，而不是自动提取能力。最小闭包相对于已声明图而定义。强化要求需要评估与义务履行语义保持不变。共同后果取决于已记录的解读和后果关系。后向切片要求无环图具有完整依赖、固定输入和确定性函数。仅凭忠实性，无法区分来源证据相同但真值不同的世界。

剩余的经验义务，是为拟议使用所依赖的表示、依赖、评估和交付提供正当依据。未知条件不能报告为已满足，空的要求集合也不能误当作不存在义务的证据。本模型给出了对这些义务的有纪律的描述；它既不确认不受限解释能力，也不确立性能优势。
