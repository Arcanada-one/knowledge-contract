# 语义类型、归属与表示 {#semantic-types-attribution-and-representations}

**作者：**Pavel Valentov · **出版版本：**1.1

## 1. 目的与符合性 {#1-purpose-and-conformance}

本文是一组架构要求。互操作性需要具名的表示配置；已实现的交换子集仅限于[观察、变更事件和配置通告](../status-model/SPECIFICATION.md#8-bounded-exchange-profile)，而[书籍包配置](../book-package/SPECIFICATION.md)具有自己的模式。这并不意味着已有完整契约的传输格式或已部署的运行时。

**SEM-R001.** 本规范定义实现在解释和表示知识时必须（MUST）保留的区别。

这些侧面用于组织内容，而不声称构成所有人类意义的穷尽分类。一个过程、一段引用的过程以及一个故意错误的过程示例，可能使用相似词语，却支持不同用途。

大写要求用语遵循 [BCP 14](../../../reference/bibliography/BIBLIOGRAPHY.md#requirement-language)。

**SEM-R002.** 符合规范的配置必须（MUST）说明其词汇、基数约束和表示映射。

[科学模型](../../../papers/semantic-objects-and-context/PAPER.md)定义来源表示、解释、依据和适用性之间的分离。

## 2. 独立的语义维度 {#2-independent-semantic-dimensions}

| 维度 | 需要保留的信息 |
| --- | --- |
| 表示 | 文本、图像、音频、视频、结构化数据或明确组合 |
| 内容类别 | 定义、观察、描述、模型、过程、结构、约束、目标、论证、问题或其他声明类别 |
| 话语功能 | 解释、指令、引用、示例、反例、问题或其他上下文角色 |
| 关于性 | 内容所指向的实体、概念或领域 |
| 归属 | 谁创作、报告、解释或评估了可寻址内容 |
| 来源立场 | 来源是在断言、提出假说、否认、提问，还是报告另一立场 |
| 运算符 | 否定、量化、模态、条件、例外、顺序及其精确作用域 |
| 评估 | 对保真度、支持或其他指定性质的观察引用 |
| 治理 | 与预期用途相关的采纳和权限记录 |
| 适用性 | 内容可使用的领域、时间、接收者及其他条件 |

**SEM-R003.** 配置可以（MAY）在一个结构化记录中存储多个维度，但不得（MUST NOT）混淆它们的含义。

来源立场不是真值。作者赞成某种方法，不等于接收者目前有权执行该方法。生成的图像描述不是原始图像。

**SEM-R004.** 对每个必需侧面，配置必须（MUST）区分已知值、未知值、有依据的不适用，以及不予披露的值。

未知不等于已知的空列表。

**SEM-R005.** 不予披露表示披露边界，不得（MUST NOT）将它表示为不存在该值的证据。

## 3. 身份、粒度与关系 {#3-identity-granularity-and-relations}

一个来源区域可以支持多个语义对象；一个语义对象也可能需要多个来源区域。

**SEM-R006.** 提取边界必须（MUST）遵循预期解释的义务。

标题中的条件、表格中的单位或图例，可能是必需的，即使它们位于检索分块之外。

**SEM-R007.** 来源身份、语义对象身份、表示身份和检索分块身份必须（MUST）保持可区分。

重新划分索引分块，不一定改变已解释的语义对象。纠正解释则需要新的语义修订版。不同呈现只有在声明的等价关系具有明确依据时，才可以保留同一语义修订版。

**SEM-R008.** 关系必须（MUST）标识其端点和类别。

导航链接建议进一步阅读；强制依赖则表示某项声明用途需要链接的信息。

**SEM-R009.** 模糊关联不得（MUST NOT）被默默提升为证明前提、因果联系或权限关系。

## 4. 作用域与歧义 {#4-scope-and-ambiguity}

**SEM-R010.** 运算符必须（MUST）绑定其实际作用域。

“并非所有成员都满足 P”不能改写为“所有成员都不满足 P”。缺少许可不是明确禁止，尽管在相应政策下，二者都可能阻止某个具体行动。被报告的假说不是已接受的结论。

**SEM-R011.** 如果多种解释仍然可能，实现必须（MUST）保留这些替代解释，或将解释标记为未决。

只有具备记录化依据并声明剩余不确定性，才允许选择其中一种解释。单独的置信分数不能说明选择了哪种解释，也不能说明哪种区别可能改变答案。

## 5. 多模态内容与交付 {#5-multimodal-content-and-delivery}

**SEM-R012.** 媒体引用必须（MUST）标识表示修订版和选择器语义。

**SEM-R013.** 必需的图例、顺序、坐标约定、单位和联合组件必须（MUST）保留。

只有当任务的受保护观察能够从文本替代物中确立时，交付该替代物才足够。

OCR、模型生成的描述、人工转录和原始视觉材料需要分别记录归属，不可混同。

**SEM-R014.** 配置必须（MUST）记录实际检查了哪一种材料。

关于转录保真度的声明需要比较方法和参照；仅仅保留所有生成描述，并不能测量它们的准确性。

## 6. 验证义务 {#6-validation-obligations}

**SEM-R015.** 符合性测试集必须（MUST）包括：带归属的错误断言、具有作用域的否定、引文中的另一层引文、措辞容易被当作指令的反例、尚未确定的替代理解，以及交付时省略了必需媒体依赖的情况。

预期行为是保留或明确拒绝；流畅的重构不能替代这些检查。

结构验证能够检查侧面是否存在、词汇以及引用，但不能确立提取器已经发现每项相关条件。因此，语义保真度需要针对具体内容的评估，并明确检查方法。

## 7. 证据与互操作性 {#7-evidence-and-interoperability}

[转录与不确定性研究](../../studies/source-transcription-and-uncertainty/STUDY.md)报告生成描述和不确定性如何在可读投影中保留。它明确将这一结果与尚未测量的 OCR 或解释准确性区分开。领域示例属于该工程研究。

[SKOS](../../../reference/bibliography/BIBLIOGRAPHY.md#skos)提供有用的概念、标签和关系；[PROV-DM](../../../reference/bibliography/BIBLIOGRAPHY.md#provenance)提供溯源方面的区别。本配置不声称取代任何一个标准，也不声称这些标准的图能够证明内容为真。

**SEM-R016.** 词汇映射必须（MUST）说明它们是精确、较宽、较窄，还是仅仅相关的对应关系。

项目首选术语见[术语表](../../../reference/glossary/GLOSSARY.md)。
